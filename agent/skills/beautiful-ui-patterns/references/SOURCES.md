## What is stored locally

The skill stores:

- pattern names and intended uses,
- original implementation-neutral guidance,
- state, accessibility, safety, and UX considerations,
- source links and the published license.

It intentionally does **not** store:

- copied component source code,
- site imagery or screenshots,
- Beautiful UI branding,
- demo content,
- or third-party logos and assets.

## When to refresh from the live site

Check the live site when the user asks for current parity, when a pattern name is unfamiliar, or when visual interaction details materially affect the work. Compare the live component list with the snapshot before changing the local catalog.

Do not silently replace local guidance with raw scraped text. Curate changes so the skill stays compact, implementation-neutral, and useful without network access.

## Copying upstream material

The official license permits use, copying, modification, and distribution of the Software and associated documentation, subject to retaining its copyright and permission notice in copies or substantial portions.

Before copying actual upstream code:

1. Verify that the material is presented as part of the MIT-licensed Software.
2. Preserve the required notice for substantial copied portions.
3. Avoid copying third-party logos, brand assets, or example content unless their rights are also clear.
4. Prefer adapting the interaction concept into the user's existing component system.

The license text bundled here is a provenance record, not legal advice.
